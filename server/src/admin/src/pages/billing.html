Kredensial Clipku Pay

Tempel merchant API key dari panel merchant Clipku Pay (regenerate bila perlu). Isi untuk mengganti key; kosongkan lalu simpan untuk menghapus nilai yang tersimpan di panel ini.
Opsional. Isi hanya bila gateway terbukti mengirim header x-clipkupay-signature — bila terisi, webhook yang signaturenya salah ditolak (401). Kosongkan lalu simpan untuk menghapus.

    Cara Mengganti Key

    1. Buka panel merchant Clipku Pay, regenerate merchant API key bila perlu.
    2. Tempel key baru di kolom atas lalu tekan Simpan.
    3. Bila status key masih "dari environment", key aktif masih berasal dari env server — ubah/hapus entri VB_CLIPKUPAY_API_KEY di env VPS, baru isi di halaman ini.
