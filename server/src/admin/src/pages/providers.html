Provider LLM

Provider + model + tarif yang dipakai builder. Hanya model yang aktif, di provider aktif, dan punya tarif yang bisa dipakai — model tanpa tarif tidak bisa dipakai (anti-rugi).

Nilai API key tidak pernah ditampilkan di halaman ini — hanya status terpasang/belum. Isi field key untuk mengganti key; simpan dalam keadaan kosong (dengan konfirmasi) untuk menghapus key yang tersimpan di panel. Key dari environment server tetap berlaku bila tidak ada key panel.
