Cadangan & Pulihkan

Unduh salinan database, atau pulihkan dari file cadangan. Setiap pemulihan otomatis menyimpan cadangan database aktif terlebih dahulu.

File .bak-<waktu> dibuat otomatis setiap kali pemulihan berhasil — itu cadangan database aktif sebelum diganti. Pulihkan dari file itu memakai jalur validasi yang sama seperti unggahan.

Pulihkan dari File

Unggah file .db hasil unduhan cadangan. File divalidasi dulu (integritas SQLite + tabel inti); bila tidak valid, database aktif tidak diubah. Bila valid, server menyimpan cadangan otomatis lalu restart sendiri dengan database baru.
