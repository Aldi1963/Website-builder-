Pengumuman

Pengumuman untuk semua pengguna. Hanya satu pengumuman yang aktif dalam satu waktu.

Pengumuman aktif akan ditampilkan sebagai banner di builder setelah perubahan penyajian dipasang (belum tersedia — lihat catatan di bawah).
JudulIsiStatusDibuatAksi

Catatan

Menampilkan banner di builder semua pengguna masih tertunda: butuh endpoint publik (mis. GET /api/announcements/active) di app.ts + komponen banner di platform/*. Pengumuman yang dibuat di sini tersimpan di database dan siap ditampilkan begitu penyajian dipasang.
